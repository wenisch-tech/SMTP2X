Access control

Administration

OIDC users start Pending. Local users can be created and their passwords changed here.

Create local user

Passwords must contain at least eight characters. OIDC-only users cannot have a local password.

SMTP listener

SMTP is enabled by default on port 2525. Set SMTP2X_SMTP_USERNAME, SMTP2X_SMTP_PASSWORD, and SMTP2X_SMTP_AUTHENTICATION=REQUIRED to bootstrap an SMTP account.

Set SMTP2X_ADMIN_PASSWORD to override the bootstrap administrator password on every startup. Without it, the initial default is admin.
